# 扩展与稳定性验证 — 2026-10-21

用户反馈：Qwen 返回无效行程，只有 London、两天、1–4 人。

## 变更

- Qwen 支持 17 个英国城市、1–14 天（首尾均计）、1–50 人；人数手动输入。sample 保持原有限制。
- 标题、天数、晚数、预算说明、默认未来日期、城市保存过滤同步更新。
- 无出发地时明确排除往返目的地交通，不再假设 Edinburgh。
- 输出失败记录安全原因，并最多修正一次；时段别名与展示标签规范化。
- 逐项费用×人数超过 Food+Activities 时，由后端补足差额并向用户披露；日期、时间冲突等检查继续保留。
- 超过三天按每段最多三天生成，最多三段并发。跨段住宿晚数计入，合并后核对日期和总价。景点跨段去重未实现，明确提示。

## 实际证据

- 18 个 unittest 通过，前端生产构建通过。
- Manchester：6 人、3 天，HTTP 200，总价 1770 GBP；初版复现费用汇总错误，修正后成功。见 results.json。
- Cardiff：浏览器生成 8 人、1 天，住宿 0，总价 608 GBP；保存、刷新、重新打开成功。见 cardiff-ui.txt 与 cardiff-result.png。
- London：按截图日期 2026-10-13 至 2026-10-24、3 人、1500 GBP。整段生成在 120 秒超时；初版分段仍因费用/显示字段校验失败。上述失败证据保留。
- 最终版本相同 London 12 天参数 HTTP 200，耗时 69.2 秒，完整 12 天，估算总价 2817 GBP。见 final-segmented-result.json。预算不够时明确显示超预算，不伪造低价。
- 原始成功段响应及请求保存在忽略版本控制的 experiments/runs/。合并记录引用段 ID；密钥未记录。

## 限制

本次是具体样例验证，不保证每次模型调用成功。未核验价格、开放时间、餐馆存在性和地理/交通可行性；长行程仍可能重复景点。旧截图当次响应未保存，无法断言那一次的具体失败字段。测试为代理执行，人工审阅待确认。
